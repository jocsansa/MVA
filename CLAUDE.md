## Claude Code

- Shell: no Windows o Bash é Git Bash e o PowerShell é 5.1; rode `npm.cmd`, não `npm`.
- Simulador e servidor em segundo plano (dois processos). Antes de reiniciar, pare o processo que
  você mesmo iniciou; não mate processos que não criou.
- Comandar a mesa pelo chat: siga "Comandar pelo chat (Claude Code)" no README — `dryRun` primeiro,
  pergunta ao usuário, uma escrita por vez, informar a leitura de volta.
- Memória do Claude para este projeto: `~/.claude/projects/c--users-jocsa-documents-mva/memory/`
  (índice em MEMORY.md). Regras do projeto ficam aqui no repositório, não na memória.
